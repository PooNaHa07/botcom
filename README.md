# ComCoach — Computer Troubleshooting Lab (ระบบจำลองห้องปฏิบัติการและแชทบอทวินิจฉัยอาการเสียของคอมพิวเตอร์)

ระบบฝึกปฏิบัติการวินิจฉัยและแก้ปัญหาคอมพิวเตอร์แบบเสมือนจริง อ้างอิงตามเอกสาร **"กิจกรรมสำรวจอาการเสียของเครื่องคอมพิวเตอร์"**

## 🌟 ฟีเจอร์หลัก (Key Features)

1. **AI ComCoach Assistant**: โค้ช AI ช่วยวินิจฉัยแบบ Socratic Method ตามกฎ 3 สาเหตุ และกฎความปลอดภัย
2. **ระบบ 4 ฐานปฏิบัติการ (4 Stations)**:
   - ฐานที่ 1: เปิดไม่ติด ไฟไม่มา (No Power)
   - ฐานที่ 2: เครื่องติด แต่จอมืด (Black Screen)
   - ฐานที่ 3: เครื่องดับหรือ Restart เอง (Random Shutdown)
   - ฐานที่ 4: เครื่องทำงานช้า (System Slow)
3. **ภารกิจผู้เรียน 6 ขั้นตอน**:
   `สังเกต ➔ ระบุปัญหา ➔ วิเคราะห์อย่างน้อย 3 สาเหตุ ➔ วางแผนตรวจสอบ ➔ เสนอ/ปฏิบัติการแก้ไข ➔ ระบุวิธีทดสอบผล`
4. **📋 ใบกิจกรรมดิจิทัล (Digital Activity Sheet)**: บันทึกผลทั้ง 4 ฐาน มีระบบดึงข้อมูลจาก AI อัตโนมัติ และสั่งพิมพ์เป็นใบงานทางการ A4 พร้อมเกณฑ์คะแนนครู
5. **💬 ระบบเก็บประวัติการสนทนา (Chat History & Archive)**: แยกประวัติตามสถานี ไม่สูญหายเมื่อสลับฐาน พร้อมระบบค้นหาและส่งออกไฟล์
6. **🎮 สำรวจคอม 3D (3D PC Case Inspector)**: หมุนดูชิ้นส่วนเคสคอมพิวเตอร์แบบ Interactive 3D (RAM, CPU, GPU, PSU, Storage)
7. **🗺️ แผนที่ & Indoor GPS Navigator**: ผังห้องแล็บ 402 พร้อมระบบนำทางระบุพิกัดเดินไปยังโต๊ะประจำฐาน

## 🚀 การติดตั้งและรันโปรเจกต์ (Getting Started)

```bash
# ติดตั้ง dependencies
npm install

# รัน Development Server
npm run dev
```

เปิดเว็บเบราว์เซอร์ที่ [http://localhost:3000](http://localhost:3000)
